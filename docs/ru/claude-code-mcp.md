# Подключение Claude Code к nerukami (MCP)

nerukami встроенно работает как MCP-сервер. После подключения Claude Code может сам смотреть
ваши аккаунты, загружать ролики, создавать черновики и планировать публикации.

## 1. Запустите nerukami

```powershell
powershell -ExecutionPolicy Bypass -File run.ps1      # Windows
```

```bash
bash run.sh                                           # macOS / Linux
```

Сервер MCP находится по адресу `http://127.0.0.1:8000/api/v1/mcp` (протокол Streamable HTTP,
JSON-RPC 2.0). Если запустили на другом порту — подставьте его.

## 2. Выпустите API-ключ

1. Войдите в nerukami: <http://127.0.0.1:8000/>.
2. Откройте **Organization → API Keys** (адрес `http://127.0.0.1:8000/organizations/api-keys/`).
3. Нажмите выпуск нового ключа, выберите рабочее пространство, аккаунты соцсетей, к которым у агента
   будет доступ, и права. Для публикации роликов нужны `create_posts`, `publish_directly` и `upload_media`.
4. Скопируйте ключ (начинается с `bb_studio_`). Он показывается один раз — nerukami его не хранит.

Ключ даёт доступ к вашим соцсетям: не публикуйте его и не коммитьте в git.
Отозвать ключ можно на той же странице, это действует сразу.

## 3. Добавьте сервер в Claude Code

```bash
claude mcp add --transport http nerukami http://127.0.0.1:8000/api/v1/mcp \
  --header "Authorization: Bearer bb_studio_ВАШ_КЛЮЧ"
```

Проверка: `claude mcp list` — у `nerukami` должно быть `✓ Connected`. В самом Claude Code команда
`/mcp` показывает сервер и список его инструментов (`list_accounts`, `create_draft`,
`schedule_post`, `upload_media`, `get_post` и другие; полный список — в
[README.upstream.md](../../README.upstream.md#mcp-tools)).

Чтобы сервер был доступен во всех проектах, добавьте `--scope user` после `add`.

## 4. Пример: пробный Reels в Instagram

Напишите в Claude Code:

> Выложи этот ролик в Instagram в пробном режиме: `D:\video\reel.mp4`, подпись «Как я перестал постить руками»

Что сделает агент:

1. `list_accounts` — найдёт ваш Instagram-аккаунт и его `id`.
2. Загрузит видео в медиатеку. Файлы больше 1 МБ через MCP на локальной установке не передать
   (`upload_media` принимает до 1 МБ), поэтому агент отправит файл через REST тем же ключом:

   ```bash
   curl -F "file=@D:/video/reel.mp4" \
     -H "Authorization: Bearer bb_studio_ВАШ_КЛЮЧ" \
     http://127.0.0.1:8000/api/v1/media/
   ```

   В ответе будет `id` медиафайла.
3. `schedule_post` с полями `social_account_id`, `caption`, `media_asset_ids`, `scheduled_at`
   (время с часовым поясом, например `2026-10-17T18:00:00+05:00`) и `instagram_trial`.

Значения `instagram_trial`:

| Значение | Что происходит |
|---|---|
| `MANUAL` | ролик видят только те, кто на вас не подписан, пока вы сами не переведёте его подписчикам в приложении Instagram |
| `SS_PERFORMANCE` | Instagram сам покажет ролик подписчикам, если он хорошо зайдёт |

Если вы не уточнили режим, агент может спросить или выбрать `MANUAL`. Чтобы ролик ушёл в
назначенное время, должен работать обработчик публикаций — `run.ps1` / `run.sh` запускают его сами.

## Если не работает

- **401 Unauthorized** — ключ скопирован не полностью или отозван; выпустите новый.
- **403 / нет прав** — у ключа нет нужного права (`create_posts`, `publish_directly`, `upload_media`)
  или аккаунт не входит в его список.
- **Connection refused** — nerukami не запущен или запущен на другом порту.
- **Публикация в Instagram падает с ошибкой загрузки медиа** — Instagram скачивает файл по ссылке
  с вашего сервера, а `127.0.0.1` ему недоступен. Прямая загрузка с локального компьютера без туннеля
  сейчас в работе; до её выхода нужен публичный адрес (туннель или сервер).
